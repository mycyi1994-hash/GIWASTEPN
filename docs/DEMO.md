## 이 영상이 증명해야 하는 것

심사자가 2분 30초를 보고 나서 **"이건 목업이 아니라 진짜 돌아가는 앱이다"**
한 문장을 확신하면 성공입니다. 그래서 이 대본은 기능을 전부 보여주지 않습니다.
**목업으로는 흉내 낼 수 없는 것**만 골랐습니다.

| 보여줄 것 | 왜 |
|---|---|
| **실외에서 GPS 경로가 실시간으로 그려지는 장면** | 이게 유일하게 위조가 불가능한 증거입니다 |
| 걸음 수가 실제로 올라가고 SUP가 적립되는 순간 | 숫자가 살아 움직이는 걸 봐야 믿습니다 |
| 랩이 자동으로 잘리는 순간 | 로직이 실제로 돈다는 증거 |
| 화면 전환의 매끄러움 | 네이티브 앱이라는 증거 (웹뷰 목업은 티가 납니다) |
| 온체인 현황을 **정직하게** 적은 마지막 카드 | 과장하면 심사에서 더 크게 깎입니다 |

**보여주지 말 것:** 정적인 화면 오래 두기, 설정 메뉴 훑기, 아직 없는 기능 암시.

## 촬영 준비

### 1) 녹화 방식 — 두 번에 나눠 찍습니다

| | 장소 | 촬영 대상 | 방법 |
|---|---|---|---|
| **A 세션** | **실외** (공원·강변 등 개활지) | 러닝 화면에서 GPS 경로가 그려지는 장면 | 안드로이드 **화면 녹화** 켜고 5~8분 걷기 |
| **B 세션** | 실내 | 나머지 UI 전부 | 안드로이드 **화면 녹화**로 화면별 짧게 |

A 세션이 이 영상의 핵심입니다. **반드시 실제로 걸으면서** 찍어야 경로가 그려집니다.

> 📍 **GPS 팁** — 건물 사이나 지하는 피하세요. 시작 후 GPS 배지가 켜지고
> 30초~1분쯤 지나야 경로가 안정적으로 그려집니다. 그 앞부분은 나중에 잘라냅니다.

### 2) 안드로이드 화면 녹화 켜는 법

1. 화면 맨 위에서 **아래로 두 번** 쓸어내려 빠른 설정 패널을 엽니다
2. **화면 녹화** 타일을 찾습니다 (없으면 연필/＋ 아이콘 → 타일 추가)
3. 탭 → **소리: 없음** 선택 (배경음은 나중에 넣습니다) → **시작**
4. 3초 카운트다운 후 녹화 시작
5. 끝낼 때는 상단 알림바를 내려 **중지**

> 삼성 기기는 `설정 → 유용한 기능 → 화면 캡처 및 화면 녹화`에서
> **동영상 화질을 1080p**로 올려두세요.

### 3) 촬영 전 앱 세팅 (중요)

빈 계정으로 찍으면 화면이 전부 `0`이라 초라해 보입니다. **미리 데이터를
만들어두세요.**

- [ ] 앱을 **한 번 이상 실제로 사용**해서 누적 걸음·거리를 쌓아둡니다
- [ ] **스니커즈를 최소 1개 민팅**하고 착용 (아이템 탭)
- [ ] **코스를 최소 1개 저장** (코스 만들기)
- [ ] 배터리 **50% 이상**, 알림 팝업이 뜨지 않게 **방해 금지 모드 ON**
- [ ] 화면 밝기를 **최대**로 (야외 촬영 시 필수)
- [ ] 앱 언어를 **영어**로 바꿔두면 해외 심사자에게 유리합니다
      (프로필 → 설정 → 언어 → English). 한국어로 두고 영어 자막을 얹어도 됩니다.
